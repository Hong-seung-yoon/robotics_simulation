## 1. 연구 문제

**Q. 평지에서 학습한 Ant는 처음 보는 지형에서 왜 걷지 못하는가, 그리고 학습 설정(iteration, PPO 하이퍼파라미터)은 원본 그대로 둔 채 환경·관측·보상 설계만으로 무엇을 바꾸면 "자연스럽게, 넘어지지 않고, 처음 보는 지형과 장애물을 지나" 걷게 되는가?**

baseline(Isaac-Ant-v0, PPO 1000 iter)을 "마찰만 바꾼 평지"와 "지형을 바꾼 환경"에서 따로 평가하고, 넘어진 순간의 자세와 걸음새를 기록해 원인을 분리했다.

| 환경 | baseline 리워드 | 관찰 |
|---|---|---|
| 평지, 마찰 1.0 / 0.3 / 1.6 | 134.9 / 126.7 / 90.8 | 마찰 변화에는 비교적 강함 |
| 격자 상자 (조교 예시 이미지형) | 9.0 | 상자 위에서 거의 못 움직임 (평균 속도 0.8 m/s) |
| 처음 보는 어려운 지형 (held-out B) | 10.0 | 59%가 중간에 종료 |
| 넘어진 순간 자세 (320마리) | 전원 전복 | 빠르게 달리다 걸려 뒤집힘 |
| 평지 걸음새 | 수직 속도 RMS 0.99 m/s, 속도 8.2 m/s | 뛰어서 달리는 걸음 |

진단: 병목은 마찰이 아니라 **지형 분포 이동**, 실패 양상은 **고속 전복**, 그리고 원본 보상(전진 거리)만으로는 **뛰는 걸음**이 최적이 된다. 여기서 일곱 가지 가설을 세웠다.

## 2. 가설과 검증 설계

| 가설 | 근거 (사람·개미가 험지를 걸을 때의 경험) | 검증 실험 |
|---|---|---|
| **H1** 다양한 지형을 겪게 하면 처음 보는 지형에도 일반화된다 | 여러 길을 걸어 본 쪽이 새 길도 잘 걷는다 | 물리 랜덤화만 / 지형만 / 지형+물리 ablation |
| **H2** 지형을 볼 수 없는 정책은 평지에서도 느려지고, 앞 바닥을 보게 하면 회복된다 | 눈 감고 걸으면 평지에서도 조심조심 걷는다 | 평지 비율 40% (여전히 blind) vs 높이 스캐너 관측 |
| **H3** "안전 우선"을 보상에 넣으면 생존은 늘고 속도는 준다 | 넘어지기 싫으면 속도를 줄인다 | 연속 안정성 페널티 vs 전복 1회 페널티 |
| **H4** 발이 걸리는 과정을 시간적으로 기억하면 더 잘 넘는다 | 방금 발이 걸린 감각이 다음 발을 바꾼다 | 3 step 관측 히스토리 |
| **H5** 실험 간 차이가 학습 seed 노이즈보다 큰가 | 결론에는 반복이 필요하다 | 같은 설정 seed 재현, 최종 설정 3 seed |
| **H6** 앞을 막는 장애물을 피하는 것도 같은 관측으로 배울 수 있다 | 벽이 보이면 돌아간다 | 학습 지형에 기둥 추가, 학습에 없던 상자·원뿔 장애물 코스로 검증 |
| **H7** "튀지 않고 바닥에 붙어 걷기"를 우선하면 전진 거리를 얼마나 잃는가 | 험지에서는 몸을 튕기지 않고 발을 부드럽게 옮긴다 | 바운스·회전·행동 변화·관절 가속 벌점을 3단계 강도로, 토크 한계 축소까지 |

### 공통 조건 (조교 공지 준수)
- **학습 설정은 원본 그대로**: 1000 iteration, 4096 envs, PPO 하이퍼파라미터·네트워크(400-200-100 ELU)·행동(토크, scale 7.5) 모두 Isaac-Ant-v0와 동일. 바꾼 것은 환경·관측·보상뿐이다. (개발 중 3000 iteration·entropy 변경 실험도 했으나 기준 위반이라 최종 후보에서 제외하고 참고 결과로만 남긴다.)
- **로봇 변형**: 하드웨어·USD 무변경. 센서(레이캐스터)는 환경 cfg에서 추가. 토크 한계 변경은 cfg에서 실험만 하고 최종에 쓰지 않았다.
- **학습 환경**: 지형 생성기 14종 × 20단계 난이도 — 평지, 요철, 오르막·내리막 피라미드 경사(최대 24°), 계단 정/역, 격자 상자(최대 16 cm), 파형, 불연속 장애물, 반복 상자, 강한 요철, 징검다리, **기둥(높이 0.6 m, 돌아가야 함)**. 전진 거리 기반 커리큘럼. 마찰 0.3~1.5·질량 ×0.7~1.3·외력 push 랜덤화. 레이캐스터 기반 지형 상대 높이 종료 조건.
- **관측**: 원본 60차원 + 높이 스캔 54차원(1.6 × 1.0 m, 0.2 m 격자, yaw 정렬, 몸통 앞 0.3 m) → 3 step 히스토리 = 342차원.
- **평가**: `play_one_episode.py --seed 24 --num_envs 100`, 원본 보상 7항. 평가 태스크는 보상을 바꾼 모델이라도 원본 보상만 사용한다.

| 평가 세트 | 지형 | 학습 포함 여부 |
|---|---|---|
| 평지 1.0 / 0.3 / 1.6 | 원본 평면 | 포함 |
| 격자 상자 1.0 / 0.3 | 조교 예시형, 높이 3~15 cm | 유사 지형 포함 (in-distribution) |
| held-out A | 반복 원기둥, 반복 피라미드, 높이맵 계단, 별 바, 박스 단차 | 미포함 |
| held-out B (hard) | 레일, 별 바 8개, 2단 단차 20 cm, 역피라미드 계단, 초강 요철, 높은 장애물 | 미포함 |
| held-out C (장애물 코스) | 높은 상자·높은 원뿔(돌아가야 함), 큰 파형, 급경사 30~55% | 미포함 |
| 스트레스 | held-out B에서 마찰 0.1 / 2.0, 반발 0.5, 출발 방향 ±180° | 미포함 |

로봇은 가장 쉬운 행에서 출발해 +x로 갈수록 어려워지는 96 m를 걷는다. 리워드는 사실상 "넘어지기 전까지 전진한 거리"다.

## 3. 결과

전체 표(30개 학습)는 `results_all_experiments.md`, 걸음새 지표는 `results_gait_metrics.md`. 아래는 가설별 핵심.

### H1. 지형 다양성 → 지지 (처음 보는 지형 10 → 54)
| 모델 (1500 iter 개발 단계) | 평지 | 격자 상자 | held-out A | held-out B |
|---|---|---|---|---|
| baseline | 134.9 ± 28 | 9.0 ± 5 | 30.1 ± 28 | 10.0 ± 8 |
| 물리 랜덤화만 | 132.8 ± 28 | 31.2 ± 15 | 51.2 ± 29 | - |
| 지형 7종 + 물리 | 75.4 ± 22 | 47.2 ± 11 | 68.1 ± 22 | - |
| 지형 12종 + 물리 | 78.9 ± 21 | 52.3 ± 8 | 74.0 ± 23 | 54.5 ± 24 |

지형 다양성이 주역이고 물리 랜덤화는 마찰 대응을 보강한다(마찰 0.3 평지에서 baseline보다 높은 151.7). 대신 평지 속도가 40% 떨어졌다.

### H2. 보지 못하면 느려진다, 보면 회복된다 → 지지
| 모델 | 평지 | held-out A | held-out B |
|---|---|---|---|
| 지형 12종 + 물리 (blind) | 78.9 | 74.0 | 54.5 |
| 평지 비율 40% (여전히 blind) | 76.9 | - | - |
| + 높이 스캐너 54차원 | 90.4 | 85.4 | 67.5 |

관측에 지형 정보가 없으면 평지인지 알 수 없어 하나의 보수적 걸음새로 모든 지형을 감당한다. 앞 바닥을 보게 하자 평지와 험지가 동시에 올랐다.

### H3. 안전 우선 보상 → 생존↑ 속도↓ (trade-off)
| 모델 | 평지 | held-out A | 생존 step |
|---|---|---|---|
| 스캐너 모델 | 90.4 | 85.4 | 899 |
| + 연속 안정성 페널티 | 70.6 | 63.7 | 871 |
| + 전복 시 1회 페널티 | 71.7 | 65.3 | 935 |

연속 페널티는 모든 환경에서 해롭고, 1회 페널티는 생존을 올리지만 리워드가 25% 준다. 넘어짐이 전부 고속 전복이므로 속도와 안전은 보상 하나로 조절되는 trade-off다.

### H4. 시간적 맥락 → 지지
스캐너 + 3 step 히스토리: 평지 90.4 → 97.7, held-out A 85.4 → 87.4, held-out B 67.5 → 70.6 (1500 iter 기준).

### H5. seed 노이즈 → 5~13점
같은 설정을 다른 seed로 재학습하면 held-out B가 67.5 → 61.1(개발 단계), 최종 설정에서는 57.3 / 42.2 / 51.9(seed 42 / 7 / 99)로 흔들렸다. 단일 학습의 작은 차이로는 결론을 내리지 않았고, 최종은 3 seed 중 가장 좋은 seed 42를 제출한다.

### H6. 장애물 회피도 같은 관측으로 배운다 → 지지
학습 지형에 높이 0.6 m 원기둥 기둥을 15% 넣었다. 스캐너는 기둥을 "넘을 수 없는 벽"(스캔값 클립 -1)로 보고, 전진 보상을 받으려면 돌아가야 한다. 학습에 없던 **높은 상자·원뿔 코스(held-out C)** 에서 최종 모델은 42.3 ± 27, 생존 910 step으로 통과했다(영상 `unseen4obstacles`). 기둥 없이 학습한 같은 설정은 이 코스가 없어 직접 비교는 못 했지만, 기둥만 추가한 개발 단계 실험(B4)은 다른 지형 성능을 떨어뜨리지 않았다.

### H7. 바닥에 붙는 걸음 → 절반 강도의 벌점이 최적
최종 환경(지형 14종, 스캐너, 히스토리, 1000 iter)에서 보상만 바꿔 5개를 비교했다.

| 모델 | 평지 | 격자 상자 | held-out A | held-out B | held-out C | 바운스 RMS 격자 / 평지 | 속도 격자 |
|---|---|---|---|---|---|---|---|
| F1 원본 보상 | 85.2 | 54.1 | 80.5 | 65.5 | 49.8 | 1.12 / 1.43 | 3.1 m/s |
| **F2 + 매끄러운 걸음 벌점 (제출)** | 70.7 | 48.9 | 66.7 | 57.3 | 42.3 | **0.51 / 0.65** | 2.7 |
| F3 + 바닥 밀착 벌점 절반 | 62.8 | 45.6 | 64.6 | 48.9 | 34.1 | 0.42 / 0.65 | 2.5 |
| F4 + 바닥 밀착 벌점 | 45.2 | 34.1 | 44.8 | 34.6 | 26.8 | 0.29 / 0.53 | 1.5 |
| F5 F4 + 토크 한계 4.0 | 33.4 | 26.3 | 31.3 | 24.6 | 25.0 | 0.21 / 0.44 | 0.75 |

벌점을 세게 할수록 바운스는 줄지만 1000 iteration 예산에서는 속도가 함께 무너진다. F2는 바운스를 절반 이하로 줄이면서 처음 보는 지형 리워드를 F1의 85~88%로 지키고 생존 step은 더 높다(924 vs 876). F3는 F2보다 바운스가 조금 작지만 리워드가 더 떨어져 F2를 택했다.

### 스트레스 테스트 (held-out B, 최종 모델)
마찰 0.1: 54.2 (824) · 마찰 2.0: 42.0 (864) · 반발계수 0.5: 54.6 (882) · 출발 방향 ±180°: 37.8 (865). 어느 조건에서도 baseline의 정상 조건(10.0)보다 높고 생존 step 820 이상을 유지한다. 가장 약한 조건은 출발 방향이 크게 틀어진 경우로, 목표 방향으로 돌아서는 데 시간을 쓴다.

## 4. 분석

1. **원인 분리가 설계의 출발점이었다.** 마찰이 아니라 지형, 느림이 아니라 전복, 그리고 원본 보상에서는 뛰는 걸음이 최적이라는 세 가지 진단이 각각 H1, H3, H7로 이어졌다.
2. **사람·개미의 험지 보행 우선순위가 설계 원리가 됐다.** 앞 바닥을 본다(스캐너), 방금 발이 걸린 것을 기억한다(히스토리), 벽이 보이면 돌아간다(기둥 학습), 몸을 튕기지 않는다(걸음새 벌점). 네 가지 모두 실험으로 효과와 비용을 확인했다.
3. **학습 설정을 늘리는 대신 설계로 올렸다.** 개발 중 3000 iteration·entropy 변경으로 held-out B 81까지 올라가는 것을 확인했지만(참고 행 C), 과제 취지에 맞게 원본 학습 설정으로 돌아와 환경·관측·보상만으로 57.3을 달성했다. 둘의 차이는 학습 예산의 효과이지 설계의 효과가 아니다.
4. **실패한 시도들이 결론을 받친다.** 연속 안정성 페널티(전부 악화), baseline에서 warm start(탐색 노이즈가 이미 줄어 재학습 실패), 기둥·급경사 추가 단독(같은 예산에서 하락), PD 위치 제어 2회(센 게인은 학습 실패, 약한 게인은 수치 발산), 바닥 밀착 벌점 전체 강도와 저토크(속도 붕괴). 모두 "환경 다양성·관측 설계가 주역, 보상은 걸음새와 속도의 균형 조절"이라는 결론과 일치한다.
5. **실험 설계의 타당성 검증 사례.** 첫 학습에서 종료의 93%가 지형 격자 밖에서 레이캐스터가 hit을 못 잡아 생긴 가짜 넘어짐이었다(320마리의 종료 위치가 8 m 배수에 몰린 것으로 발견). 폴백과 격자 연장 후 held-out 리워드 27 → 55. IsaacLab 내장 종료 페널티 항이 다음 에피소드까지 플래그를 유지하는 문제도 같은 방식으로 찾아 교체했다.
6. **한계.** 평지 속도는 baseline의 52%(걸음새를 바꾼 대가). 잡음형 높이맵과 출발 방향이 크게 틀어진 경우에 약하다. 바운스는 절반으로 줄었지만 실제 개미처럼 완전히 바닥에 붙지는 않는다. 더 긴 학습이 허용되면 같은 설계로 held-out B 80 근처까지 올라감을 확인했다.
